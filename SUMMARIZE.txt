CURRENT IMPLEMENTATION

Preprocessing Pipeline (02_preprocessing.ipynb)
A six-stage pipeline producing (60, 404) feature arrays per video:

  video.mp4
    -> extract_keypoints()   [MediaPipe Holistic]  -> (n_frames, 201)
         -> compute_features()                      -> (n_frames, 404)
              -> normalize_sequence()               -> (60, 404)
                   -> augment_sequence()            -> 4 variants per training video
                        -> global z-score           -> normalized .npy files

Feature engineering in compute_features():
  - Body-relative normalization using shoulder midpoint as origin and shoulder
    width as scale
  - Frame-to-frame velocity (201 additional features)
  - Left-right wrist Euclidean distance (1 feature)
  - Dominant hand speed (L2 norm of wrist velocity, 1 feature)
  - Total: 201 raw + 201 velocity + 1 hand_dist + 1 dom_speed = 404 features

Temporal normalization: Sequences interpolated/subsampled to exactly
TARGET_FRAMES = 60

Global normalization: Mean and std computed over 72,000 training frames
(global_mean.npy, global_std.npy)

Offline augmentation (training only, N_AUGMENTS_PER_TRAIN = 3):
  Gaussian noise (sigma in 0.003-0.006), 2D rotation (+-3 degrees),
  speed variation (x0.92-1.08)

Model Architecture (03_training.ipynb Cell 3, confirmed with saved summary):

  Input (60, 404)
    -> Masking (mask_value=0.0)
    -> LSTM(64, return_sequences=True,  L2=0.02)   [120,064 params]
    -> Dropout(0.65)
    -> LSTM(32, return_sequences=False, L2=0.02)   [12,416 params]
    -> Dropout(0.65)
    -> Dense(64, relu, L2=0.02)                    [2,112 params]
    -> BatchNormalization()                         [256 params]
    -> Dropout(0.4)
    -> Dense(10, softmax)                           [650 params]
  Total trainable params: 135,370 (528 KB)

  NOTE: Cell 3 docstring refers to LSTM(128)/LSTM(64) but actual model built
  uses LSTM_UNITS = [64, 32] from configuration. The saved model at
  04_evaluation.ipynb shows a different loaded model with LSTM(128)/LSTM(64)
  and output Dense(25) -- indicating TWO DISTINCT TRAINING RUNS exist, with
  the final saved lstm_model.keras being the 25-class version.

Training Configuration:
  Batch size           : 32
  Epochs               : 200 (EarlyStopping patience=25)
  Learning rate        : 1e-4
  L2 regularization    : 0.02
  Dropout (LSTM)       : 0.65
  Dropout (Dense)      : 0.4
  Label smoothing      : 0.15
  MixUp alpha          : 0.3
  Online augments/video: 50
  Steps per epoch      : 1,875

Online augmentation in tf.data pipeline (12 families): horizontal flip,
rotation +-3/+-5 degrees, noise sigma=0.003/0.006, speed x0.90-0.95 /
x1.05-1.10, temporal shift +-2-4 frames, flip+noise, rotation+noise

MixUp implemented via mixup_batch() with Beta(0.3, 0.3) sampling

Callbacks: EarlyStopping(patience=25), ReduceLROnPlateau(factor=0.5,
patience=10), ModelCheckpoint(monitor='val_accuracy')

Evaluation Results (confirmed from notebook cell outputs):
  Best validation accuracy: 0.8000  (10-class, 10 val samples)
  F1 = 1.0:   mai di, mai, khrai
  F1 = 0.0:   sawatdi, chai
  F1 = 0.667: di
  Most-confused pair: sawatdi -> thora sap

Saved artifacts confirmed present:
  lstm_model.keras, model_info.json, training_curves.png, confusion_matrix.png
